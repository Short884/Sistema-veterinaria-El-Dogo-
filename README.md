# 🐾 Veterinaria "El Dogo"

Proyecto desarrollado en React para la gestión de clientes y mascotas.

## 🚀 Cómo probarlo
1. Descarga la carpeta src.
2. Abre la terminal en la carpeta del proyecto.
3. Instala las dependencias:
   ```bash
   npm install
   npm install react-router-dom

4. Pon en marcha el servidor para localhost:
   npm run dev

5. Pon la carpeta dentro de la raiz del proyecto, junto a las demas carpetas del proyecto, tendria que quedar tal que asi:
el-dogo-react/
├── node_modules/       # 🚫 Dependencias instaladas 
├── public/             # 🌐 Archivos públicos 
├── src/                # 💻 Hogar de la aplicación React
│   ├── assets/         # 🖼️ Imágenes, logos de la veterinaria
│   ├── components/     # 🌟 Componentes
│   │   ├── Clientes.jsx  <-- (Código de Clientes)
│   │   └── Mascotas.jsx  <-- (Código de Mascotas)
│   ├── App.css         # 🎨 Estilos para el componente principal
│   ├── App.jsx         # 🧠 Componente padre
│   ├── index.css       # 🎨 Estilos globales base
│   └── main.jsx        # 🚀 Punto de entrada (Conecta React con el index.html)
├── index.html          # 📄 La página
├── package.json        # 📦 Listado de librerías y scripts del proyecto
└── vite.config.js      # ⚙️ Configuración interna de Vite

6. Ya con eso la aplicación funcionaria, para cerrar el servidor haz la combinación de teclas Ctrl + C, y dale a S. Esto apagara el servidor del sistema.
